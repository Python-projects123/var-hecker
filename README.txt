SCRATCH VARIABLE EDITOR v2.0

Target site: https://ninja.greninja.xyz/

INSTALL IN FIREFOX (temporary add-on)
1. Extract this ZIP into a folder.
2. Open about:debugging#/runtime/this-firefox
3. Click Load Temporary Add-on...
4. Select manifest.json from this folder.
5. Reload the Ninja Greninja project page.
6. Click the extension button and choose Refresh variables.

If the extension cannot find the VM, the site may keep its Scratch runtime
inside a private bundle, sandbox, or cross-origin frame. This extension cannot
access a runtime that the page does not expose. It edits live runtime values
only and does not change the saved project file.

Use only on projects you are authorized to inspect or modify.
